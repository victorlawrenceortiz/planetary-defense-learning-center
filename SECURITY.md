# Security Policy

## Public repository boundary

This repository is public and must not contain secrets or private operational details.

Do not commit:

- API keys, tokens, passwords, or credentials
- Private IP addresses or internal network diagrams
- Observatory control endpoints or procedures
- Firewall/router/VPN configuration
- Private incident details

## Reporting a security issue

If you find sensitive data in this repository, do not open a public issue with the secret value. Contact the repository owner privately and request immediate rotation/removal.
