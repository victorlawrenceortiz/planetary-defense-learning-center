# Contributing

Thank you for helping improve public planetary-defense education.

## Style

- Use calm, clear, public-safe language.
- Cite authoritative sources where possible.
- Separate education from official emergency instructions.
- Avoid sensational claims or unsourced impact predictions.

## Source priority

Preferred sources include NASA/JPL CNEOS, NASA Planetary Defense, the Minor Planet Center, IAWN, ESA planetary defense resources, NOAA/FEMA/Ready.gov, and local emergency-management agencies.

## Safety

Never contribute secrets, private infrastructure details, or observatory control information.
