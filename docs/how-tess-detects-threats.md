# How TESS Detects Threats

TESS supports public awareness by combining official near-Earth object data, observatory readiness checks, and clear mission dashboards into one understandable workflow.

## The basic idea

TESS does not invent asteroid warnings. It organizes public data, local observatory readiness, and mission status into practical displays that help people understand what is happening.

## Evidence before alarm

A dashboard notice is not an impact prediction. Every public statement should trace back to authoritative sources and current observations.

## Practical workflow

1. **Use official feeds** — start with NASA/JPL, Minor Planet Center, IAWN, and other authoritative sources.
2. **Check freshness** — confirm that data timestamps and dashboard feeds are current before interpreting them.
3. **Compare context** — look at size estimates, miss distance, velocity, uncertainty, and time until close approach.
4. **Check readiness** — confirm whether observatory, AllSky, communication, and website systems are healthy.
5. **Explain plainly** — translate technical data into calm public language without exaggeration.
6. **Escalate carefully** — only elevate concern when evidence and official sources support it.

## What TESS can show

- Closest public close-approach summaries.
- Mission dashboard health and data freshness.
- Links back to NASA/JPL and other official sources.

## What TESS should avoid

- Claiming official warning authority.
- Presenting stale data as current.
- Turning routine close approaches into panic language.
