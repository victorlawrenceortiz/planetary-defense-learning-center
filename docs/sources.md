# Sources

Preferred authoritative sources for public planetary-defense education:

- [NASA Planetary Defense](https://science.nasa.gov/planetary-defense/)
- [NASA/JPL CNEOS](https://cneos.jpl.nasa.gov/)
- [Minor Planet Center](https://minorplanetcenter.net/)
- [International Asteroid Warning Network](https://iawn.net/)
- [Ready.gov](https://www.ready.gov/)
- [Ready.gov Alerts](https://www.ready.gov/alerts)
- [Ready.gov Kit](https://www.ready.gov/kit)
- [Ready.gov Plan](https://www.ready.gov/plan)

TESS/Planetary Defense Foundation materials should cite official sources first and clearly distinguish public education from official emergency instructions.
